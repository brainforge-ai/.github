# Brainforge

We build data and AI systems that ship. Brainforge works with teams on data platforms, analytics engineering, and production AI.

We publish the tools we use on client work in the open. They are read-only by default, run locally, and collect no telemetry.

## Accelerators

| Tool | What it does | License |
| --- | --- | --- |
| [ClickHouse Optimization Audit](https://github.com/brainforge-ai/clickhouse-optimization-audit) | Audits one ClickHouse Cloud service read-only. Five scored areas, measured findings, a self-contained HTML report. | Apache-2.0 |

More accelerators are in progress.

## What we hold ourselves to

- **Read-only by default.** No writes to your warehouse, no row data in reports.
- **Measured, not asserted.** Every score and finding cites evidence from your system.
- **Local-first.** No backend, no hosting, no telemetry.
- **Attribution.** Vendored work keeps its license and provenance.
- **Open license.** Apache-2.0 unless a repository says otherwise.
